**RafflePlus** allows you to create engaging lottery events on your server. Players can purchase tickets using in-game currency, and the system automatically selects winners based on your configuration. It's the perfect way to sink economy money and keep players excited!

What makes **RafflePlus** special is its simplicity and visual appeal. With an intuitive GUI, players can easily understand how to participate without complex commands.

<div align="center">
  <h2>PLUGIN PROPERTIES</h2>
</div>

- **Ticket System:**
  - Configurable price per ticket.
  - Limit tickets per player (Optional).
- **Rewards:**
  - Execute custom commands for winners.
  - Give items or money directly.
- **Automation:**
  - Set automatic intervals for raffles.
  - Broadcast messages to announce winners.
- **Customization:**
  - Edit all lore and item names in the GUI.
  - PlaceholderAPI support (Coming soon).

<div align="center">
  <img src="https://i.imgur.com/vdk0Q5C.png" alt="Commands"/>
</div>

```yaml
/raffle           - Opens the main Raffle GUI.
/raffle buy       - Quick command to buy a ticket.
/raffle reload    - Reloads the configuration file.
```

<div align="center">
  <img src="https://i.imgur.com/lxNkr6T.png" alt="Permissions"/>
</div>

- `r.buy` - Allows players to open the menu and buy tickets (Default: true).
- `r.reload` - Admin permission to reload the plugin (Default: OP).

<div align="center">
  <img src="https://i.imgur.com/7ZZmjdX.png" alt="Installation"/>
</div>

1. Download **RafflePlus.jar**.
2. Install **Vault** and an economy plugin (like EssentialsX).
3. Drag RafflePlus into your `plugins` folder.
4. Restart your server.
5. Configure `config.yml` to your liking!
